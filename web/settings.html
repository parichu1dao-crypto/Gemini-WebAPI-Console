运行策略 / Runtime policy

仅连接现有服务，不启停它、不新开浏览器。所有轮询账号共同支持的模型才可选择；不自动降级。浏览器需要保持运行。

开启：无法确认付费权限和动态Pro模型时拒绝。关闭：跳过额外校验，不代表保证实际模型，不自动转换成Flash。

通道说明 / Channel guide

1. Cookie 后台调用 / Background Cookie API

使用已验证账号的 Cookie 在后台发送请求。生成时无需打开网页或保持浏览器运行；登录过期时需要重新登录并导入。模型来自服务动态列表，包括上游实际开放的 Pro、Argon 等；不是所有账号都有相同模型权限。

Sends requests in the background using verified account cookies. No browser window is required during generation. Expired sessions require sign-in and re-import. Models come from the live service catalog; Pro or Argon availability depends on the upstream account.

2. 已有服务转发 / Existing upstream relay

转发到你配置的上游服务，不会自动把 Cookie 通道变成浏览器通道。若上游使用网页自动化，必须先打开要调用账号的独立浏览器，登录 Gemini 并保留 Gemini 页面和浏览器进程；普通默认浏览器或其他账号的窗口不能替代。若上游使用 Cookie，则按 Cookie 的要求运行。

Forwards to the configured upstream service; it does not change that service's transport. A browser-automation upstream requires the correct dedicated account browser to be open, signed in to Gemini, with its Gemini tab and browser process kept running. Your default browser or another account's window is not a substitute. Cookie upstreams follow the Cookie requirements above.

3. 本台托管网页池 / Managed browser pool

录入账号 → 打开独立登录窗口 → 管理员登录 → 核对邮箱与身份 → 启用账号。调用前先打开对应 Gemini 页面；调用期间不要关闭、退出登录或手动操作该页面。本台托管池与已有生产池独立，新账号不会自动加入其他服务。

Add an account, open its dedicated login window, sign in, verify its email and identity, then enable it. Open the account's Gemini page before calling the API. Do not close, sign out of, or manually operate that page during generation. This managed pool is separate from the existing production pool.

账号启停 / Account start and stop

停止账号会立即禁止它接收新的请求；已接收的生成允许完成，不会关闭浏览器。启动只恢复调度资格，不会清除额度或故障冷却，也不会自动修复过期登录。历史账号未绑定有效服务和浏览器时，不显示可用的启停按钮。

Stop prevents new admissions; already admitted requests may finish and the browser remains open. Start restores admission eligibility but does not clear quota limits, failure cooldowns or expired sessions. Historical accounts without a live service binding cannot be started here.

API 设置 / API settings

以此处显示的 Base URL 为准。Cookie 使用独立服务端口；转发和托管入口使用管理台端口。上游地址与客户端调用地址不是一回事。

Use the Base URL shown above. Cookie uses its own service port; relay and managed APIs use the console port. The upstream URL is not necessarily your client-facing endpoint.

请求显式传入的 model 优先于保存的默认模型。API 密钥与管理密码分开；保存本入口密钥不会修改另一个上游服务的密钥。

An explicit request model overrides the saved default. API keys and the management password are separate; changing this entrypoint's key does not change another upstream service's credentials.

限额保护

优先读取网页恢复时间；读取不到时冷却12小时。取消勾选表示管理员允许使用基础 Flash-Lite 模型继续，实际模型会如实记录。已发送的请求不自动重发。

适用于本台托管池和已接入的本机浏览器服务；生产服务首次升级需要重启，之后策略保存即时生效。Cookie 通道不具备网页限额检测。
